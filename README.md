# K-NN Classification on Digits Dataset

## 📜 Description
This project demonstrates the use of the **k-Nearest Neighbors (k-NN)** algorithm to classify handwritten digits. It uses the `digits` dataset from the `scikit-learn` library, which contains 8x8 grayscale images of digits (0–9).

The goal is to explore how the k-NN algorithm performs on this dataset and visualize the results.

---

## 🛠 Features
 - Data Visualization: Visualizes sample digits from the dataset.
 - Model Training: Implements K-NN to classify digits.
 - Model Evaluation: Analyzes the model's accuracy and visualizes the precision based on the number of neighbors (k).
 - Performance Tuning: Tests different values of k (from 1 to 20) to identify the best-performing configuration.

## 📊 Results
 - Precision Score: 96.67%
 - Visualized precision changes with varying numbers of neighbors.
 - Insights on optimal k values for better performance.

## 🚀 Technologies Used
 - Programming Language: Python
 - Libraries:
    - pandas for data handling
    - numpy for numerical computations
    - matplotlib for visualizations
    - sklearn for machine learning models and evaluation
